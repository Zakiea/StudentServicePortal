# Student Service Portal

A responsive student portal website built with HTML, CSS, and JavaScript for managing common student information and support pages.

## Overview

This project is a simple front-end portal designed for students to access key information such as:

- Student details
- Enrolment information
- Marks and results
- Help and support resources

The site is styled to match a university/college portal experience and includes navigation, banners, tables, and a footer consistent across pages.

## Features

- Home landing page with quick access cards
- Student details page with profile information
- Enrolment page for active and previous enrolments
- Results page displaying subject marks and outcomes
- Help and support page for student assistance
- Responsive layout for desktop, tablet, and mobile screens
- Modern icon styling via Font Awesome
